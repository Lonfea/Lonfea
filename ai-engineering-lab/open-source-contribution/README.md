# Open-Source Contribution Track

This folder exists to turn portfolio work into a **real upstream contribution**, not to simulate one.

## Target projects

Preferred ecosystems:
- LangGraph
- CrewAI
- LlamaIndex

## Contribution standard

A contribution only counts here after it has:
1. a real upstream issue or reproducible bug/feature request;
2. a minimal reproduction;
3. a focused patch on a fork/branch;
4. tests that fail before and pass after;
5. documentation or changelog updates when appropriate;
6. an upstream pull request URL;
7. maintainer feedback recorded in this folder;
8. final status: open, merged, or declined.

## Candidate areas surfaced by this lab

The projects in this repository create realistic contribution opportunities around:
- durable human-in-the-loop checkpoint examples;
- structured multi-agent audit trails;
- RAG citation/evaluation examples;
- clearer production deployment documentation;
- integration edge cases discovered while upgrading dependencies.

## Evidence file

When a real PR is opened, add `CONTRIBUTION.md` with:

    Upstream repository:
    Issue:
    Pull request:
    Problem:
    Reproduction:
    Patch:
    Tests:
    Maintainer feedback:
    Status:

Do not add a fake PR number, fake maintainer quote, or claim a merge that did not happen.
